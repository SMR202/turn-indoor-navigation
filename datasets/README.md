# Datasets

Update 2026-09-24: an original [synthetic venue fixture](../packages/venue-model/src/sample-venue.ts) exists for product/tests. No real sensor or venue dataset has been validated. The policy below applies to future collection.
Store metadata and safe small synthetic fixtures in Git. Raw sensor logs, identifiable movement traces and venue floor plans stay outside Git in authorized storage. Record access reference, rights, SHA-256, units, clocks, coordinate frames and ground truth in the session manifest. Keep raw files immutable; put derived outputs separately. No dataset is currently available or validated.
