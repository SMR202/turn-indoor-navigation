## Gaps with no reusable selection

**IMPLEMENT:** TURN venue-map schema/topology, monotonic observation envelope, native
capability adapters, deterministic replay, mobile routing boundary, and integration
contracts. These encode project semantics or platform lifecycles.

**EXPERIMENT:** automatic extraction, step/stride, magnetic fingerprints, BLE value,
Android Wi-Fi value, multimodal fusion, map constraints, floor inference and
cross-device calibration. No reviewed repository is a licensed, maintained,
cross-platform, empirically validated drop-in for these combined requirements.

## Audit mechanics and limitations

GitHub REST API supplied default-branch metadata, latest commit objects, README and
license contents. A smart-HTTP clone attempt for every deeply inspected candidate
was blocked with HTTP 403 under the environment's GET/HEAD/OPTIONS policy, so no
build was attempted and transitive dependency/license scans remain pending before
any code adoption. Dataset/model/weight rights are independent of source licenses;
none are accepted by this registry. Re-check the pinned tree, release artifacts,
minimum OS/build requirements, transitive licenses and security posture at the time
of integration.
