### Dependency audit limitation

Root npm audit on 2026-09-24 reports 13 moderate transitive findings, no high/critical: uuid 7.0.3 through Expo's xcode tooling and decode-uri-component 0.2.2 through Router/query-string, plus affected ancestor packages. Suggested automated fixes downgrade Expo/Router across major versions. No force downgrade/unsupported override was applied. Updated decode-uri-component is ESM while the current consumer uses CommonJS; blindly overriding can break the app. Track compatible upstream fixes and reassess before external deep-link/QR inputs or shipping. Installed xcode uses uuid.v4, whereas the reported buffer issue concerns other UUID functions; this narrows observed use but is not a blanket security clearance.

cross-device calibration. No reviewed repository is a licensed, maintained,
cross-platform, empirically validated drop-in for these combined requirements.

## Audit mechanics and limitations

GitHub REST API supplied default-branch metadata, latest commit objects, README and
license contents. A smart-HTTP clone attempt for every deeply inspected candidate
was blocked with HTTP 403 under the environment's GET/HEAD/OPTIONS policy, so no
build was attempted and transitive dependency/license scans remain pending before
any code adoption. Dataset/model/weight rights are independent of source licenses;
none are accepted by this registry. Re-check the pinned tree, release artifacts,
minimum OS/build requirements, transitive licenses and security posture at the time
of integration.
