# TURN interaction contract

Evidence: [project state](docs/PROJECT_STATE.md), [architecture](docs/ARCHITECTURE.md), [local venues](docs/LOCAL_VENUES.md), [dataset policy](datasets/README.md). This document records UI behavior, not new positioning guarantees.

| Capability             | Canonical owner                           | Behavior / verification                                                                                                                                                                              |
| ---------------------- | ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Navigation             | Expo Router tabs in `_layout.tsx`         | Navigate, Survey, Tests remain available. Leaving a capture cancels it; leaving a walking session stops acquisition through existing lifecycle handling.                                             |
| Form                   | Native TextInput and shared Action        | Visible labels, explicit actions, persistent errors, no duplicate capture/submission. Search has a clear action.                                                                                     |
| Select/Listbox         | Labelled Pressable choice lists           | Selected state exposed; no authored dropdown. Station choice uses map label and recorded pass count.                                                                                                 |
| Feedback               | Shared Notice                             | Inline persistent error/status, accessible live region; no toast-only failure.                                                                                                                       |
| Scrollbar              | Native ScrollView / web global stylesheet | Visible platform indicators; browser thumb and focus follow shared baseline.                                                                                                                         |
| Survey CRUD            | fingerprinting/storage.ts                 | Completed captures saved locally. Cancellation discards only in-progress readings. Previous raw records retained. No destructive bulk-delete flow in this slice.                                     |
| Fingerprint correction | Pure matcher plus user confirmation       | Ambiguous/outside-survey readings do not establish location. User confirms surroundings before applying a candidate as an anchor. Never silently move navigation based on a single magnetic reading. |
| Sharing                | Existing paired LAN transfer              | Only user-triggered upload, receipt required, local recordings preserved on failure. Fingerprint records include hashed radio identifiers, never SSIDs.                                              |

Survey ground truth comes from physically confirmed map locations, not PDR. Test labels are added after capture and excluded from matching. Survey is per device and venue revision; cross-device calibration is unvalidated. Native permission UI remains OS-owned. Android Wi-Fi is optional and does not block magnetic collection when unavailable or denied. No paid service, cloud survey upload or location permission request occurs just by opening the app.
